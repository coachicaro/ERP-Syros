Configurar banco de dados
Para salvar e sincronizar todos os dados entre o time, conecte ao seu projeto Supabase.
1. Acesse supabase.com e crie um projeto gratuito
2. Vá em Project Settings → API
3. Copie a Project URL e a anon public key
4. No SQL Editor, rode o script abaixo para criar as tabelas
-- Cole no SQL Editor do Supabase e execute: create table clientes (id uuid primary key default gen_random_uuid(), created_at timestamptz default now(), nome text, cpf_cnpj text, telefone text, email text, tipo text, cidade text, estado text, observacoes text); create table apolices (id uuid primary key default gen_random_uuid(), created_at timestamptz default now(), numero text, cliente_id uuid references clientes(id), seguradora text, ramo text, vigencia_inicio date, vigencia_fim date, premio_anual numeric, comissao_pct numeric, status text, observacoes text); create table sinistros (id uuid primary key default gen_random_uuid(), created_at timestamptz default now(), apolice_id uuid references apolices(id), cliente_id uuid references clientes(id), data_abertura date, tipo text, descricao text, valor_estimado numeric, status text, data_resolucao date, observacoes text); create table comissoes (id uuid primary key default gen_random_uuid(), created_at timestamptz default now(), apolice_id uuid references apolices(id), competencia text, valor numeric, status text, data_pagamento date, observacoes text);
🔒 Suas credenciais ficam salvas apenas neste navegador. Use a chave anon (pública) — nunca a service_role.
